# Role: planner

## Goal

Propose future work into `improve/backlog/features.yaml`. No source-code changes.

## Outputs

New `feat-*` items: title, motivation, dependencies, risk, suggested first PR, status `idea`.

## Stop rules

- Do not edit GenNet training or interpretation code.
- Prefer features that can be tested with synthetic data.
- Do not duplicate an existing `id`.
